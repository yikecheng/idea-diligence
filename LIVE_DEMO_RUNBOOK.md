# Live demo runbook

Start the app from the project directory with `python -m streamlit run app.py` and use the localhost address it prints. Keep that terminal open through the demo.

## Rehearse the handoff

1. Open **Catch Me Up on Anything** from **Workspace home**. Confirm the case shows five assumptions and its repeat-listening experiment.
2. Open **Evidence** and show the AnyPod source passage. Explain that it challenges differentiation. The claim about repeat listening still needs the pilot.
3. Show **Experiment** and its four-of-eight threshold. Open **Overview → Download decision memo** if you want to show what a founder can share.

## Show a genuinely new idea

1. Select **New idea → Local evidence review**. Use the example fields below or a new idea from the audience.
2. Open **Find public discussion leads**, type `AI podcast`, and click **Search Hacker News**. Open one native HN result. The app sends the search terms and labels the stories as research leads.
3. Click **Save analysis** to rank and store the brief. **Run trace** shows one public search submission and zero model calls. **Experiment** lets you add a test plan after saving, and the shareable memo downloads from **Overview**.

| Field | Quick rehearsal input |
| --- | --- |
| Idea name | Product Brief Listening Lab |
| Target customer | PMs catching up on technical launches |
| Problem | Reading scattered announcements takes too long before team meetings. |
| Proposed solution | A short, source-linked audio briefing on a launch and its practical impact. |
| What has to be true? | PMs return with a second launch question during the same work week. |

If the external search stalls, keep talking through the brief. The search returns a success, empty result, or error within its request budget. You can save the analysis and keep demonstrating. Use an already saved case if you need to jump directly to evidence and experiment.

Suggested language for the audience: “I’m using a new brief and a live public search here. I’ll decide what counts as supporting evidence. This other case comes with a curated source set so you can reproduce the same analysis later.”

Use real observations for a real founder decision. Any sample counts entered on camera should be described as simulated.
